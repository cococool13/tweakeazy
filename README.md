# Win11 Gaming Toolkit

Windows 11 gaming tweaks you can undo. Every tweak says what it does to anti-cheat, whether you need a reboot, and whether it touches the disk.

**Site:** https://tweakeazy-site.cohencool.workers.dev

## Run it

1. Download or clone this repo.
2. Right-click PowerShell and pick Run as Administrator.
3. Run:

```powershell
cd "<path-to-repo>"
.\launcher.ps1
```

- `[V]` check current settings (does not change anything)
- `[A]` apply
- `[R]` undo everything
- `[?]` help

Read [GUIDE.md](GUIDE.md) before you apply everything the first time.

## Safety

Green tweaks are safe. Yellow ones have trade-offs. Red ones turn off real security features for speed. Those are opt-in. You can undo all of them.

More detail: [GUIDE.md](GUIDE.md), [BIOS-CHECKLIST.md](BIOS-CHECKLIST.md), [CHANGELOG.md](CHANGELOG.md).
